# Appendix 目录

本目录收录鸿蒙 Flutter 相关的补充性、全局性文档，供开发者查阅。建议所有与主开发流程无关但对开发有重要参考价值的文档均归档于此。

## 目录结构建议

- UPGRADE_GUIDE.md  —— 升级指南
- MIGRATION_GUIDE.md —— 迁移指南（如有平台迁移需求）
- VERSION_HISTORY.md —— 版本历史与变更说明
- LICENSES.md —— 依赖组件许可证说明（如需单独列出）
- GLOSSARY.md —— 术语表/名词解释
- CONTRIBUTING.md —— 贡献指南（如需补充说明）

如有其他补充性文档，也可统一归档于本目录下。

---

> 本目录仅为建议，具体内容可根据项目实际情况增删调整。
