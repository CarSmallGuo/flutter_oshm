## Version Overview
This version is an OpenHarmony version based on Flutter 3.7.12. This version supports and improves the capabilities of the OpenHarmony platform and improves stability.

## New Features
- Embed ICU data into the SO in release mode
- Adapt the mouse hover function for WebView
## BugFix
- Fixed the slipping function under PC
- Fixed the issue of bottomRect being undefined
- Fixed the problem of FlutterEntry missing system environment change listener

## Version Release Time
Sep 4, 2025

## Version Support
- OpenHarmony API20
- Flutter SDK: 3.7.12-ohos-1.1.6
