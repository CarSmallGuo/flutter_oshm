## Version Overview
This version is an OpenHarmony version based on Flutter 3.7.12. This version supports and improves the capabilities of the OpenHarmony platform and improves stability.

## Release Scope
OpenHarmony API18

## New Features
- Add dynamic library loading utility class

## BugFix
- Fixed the issue of updating the text cursor position and replacing text errors in the input method
- Fixed the problem where, when using an external physical keyboard, pressing the delete key after entering content with the Chinese input method would result in additional characters being deleted from the input box
- Fixed the flickering issue caused by the input field
- Fixed the issue that after setting the background color or background image of an external texture, it did not take effect immediately

## Version Release Time
Jun 7, 2025

- IDE: DevEco Studio 5.0.13.200
